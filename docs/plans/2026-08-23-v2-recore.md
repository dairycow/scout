# Scout v2 re-core — implementation plan (2026-08-23)

Execution of `docs/plans/architecture-plan.html` (rev 2) on branch `v2-recore`,
targeting tag `v2.0.0`. The architecture plan is the contract source; sections

## Intent

Greenfield re-core per the architecture plan: ~440-line kernel (bus, host, agent
loop, shell), eight internal plugins under `scout/builtin/` sharing PluginApi v2
with user plugins, and a single append-only SQLite event store at
`~/.scout/store.db` with `messages` as a deterministic projection. No v1
backward compatibility; v1 modules deleted at P5.

## Method

Hybrid orchestration: sequential phases, one parallel fan-out (P2 store ‖ P3
ports — disjoint files), grok CLI workers in ephemeral worktrees, reviewer-Grok
mandatory on P1 (kernel purity) and P2 (projector/store). Gates run under
`uv run pytest -q`. Never weaken a gate; one commit per task; LOC budget ±20%
of §9 (rev 2: providers 240, total ~1,475). Survivors move unchanged except
Anthropic's §8.1 cache markup.
